# Seguridad

Second Brain 404 v2.1.0 está pensado para uso local.

Controles incluidos:

- Bind a localhost.
- Sin telemetría.
- Claves por variables de entorno.
- Upload con allow-list.
- Protección frente a path traversal.
- Tamaño máximo configurable.
- CSP, `X-Frame-Options`, `nosniff` y política de permisos.
- OUTPUT excluido de indexación.

Si se publica en una red o Internet, añade autenticación, TLS, autorización, rate limiting y gestión profesional de secretos.
